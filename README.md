# Pristine Care NJ Website

This is a Next.js (App Router) website for Pristine Care NJ, a behavioral support and community care provider.

## Tech Stack
- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Fonts:** [Google Fonts](https://fonts.google.com/) (Playfair Display for headers, Inter for body)

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd pristine-care-nj
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure
- `src/app`: Page routes and layouts.
- `src/components`: Reusable UI components.
- `src/app/globals.css`: Tailwind configuration and theme variables.

## Key Features
- Responsive Navigation and Footer.
- Service-specific pages (Behavioral Support, Community Care).
- Integrated Inquiry and Referral form on the Contact page.
- Careers section with job listings and culture overview.
